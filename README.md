🛠️ Key Technical Highlights

* **Machine Learning:** Random Forest
* **Prediction Accuracy:** 98.57%
* **Database:** PostgreSQL
* **Datasets:** Crop Yield, Temperature, Soil, Rainfall, Pesticides
* **User Roles:** Admin, Consultant, Farmer
* **Frontend:** React / Vite
* **Backend:** FastAPI
* **Deployment:** Docker + Render
* **Core Features:** Crop Yield Prediction, Weather Analysis, Soil Analysis, Analytics, Reports, Recommendations, Risk Assessment
